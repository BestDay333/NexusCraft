# NexusCraft — схемы и материалы

Универсальный дашборд для Minecraft-схем: загрузите файл — получите точный список блоков,
3D-предпросмотр постройки и удобный учёт заготовленных ресурсов.

Всё работает прямо в браузере: файлы схем никуда не отправляются и не покидают ваше устройство.

**Демо:** https://bestday333.github.io/NexusCraft/

## Возможности

- **Загрузка схем** — перетащите один или несколько файлов в зону загрузки.
- **Список материалов** — автоматический подсчёт блоков, уникальных материалов и общего объёма.
- **3D-предпросмотр** — вращение, масштабирование, срез по слою Y, авто-вращение и скриншот PNG.
- **Несколько проектов** — схемы суммируются в общий список; можно переключаться между ними.
- **Учёт добычи** — отмечайте собранное количество, следите за остатком и прогрессом.
- **Умные выражения** — в поле «Добыто» можно вводить `32*64`, `2 шалкера`, `1 стак + 20`, `1k`.
- **Категории** — свои категории материалов, фильтры, поиск и сортировка.
- **История изменений** — кто и сколько добавил (после входа по нику).
- **Экспорт и импорт** — сохранение проекта в JSON и перенос на другое устройство.
- **Локальное хранение** — проекты, прогресс и категории остаются в браузере (`localStorage`,
  исходные файлы — в `IndexedDB`), поэтому предпросмотр работает и после перезагрузки страницы.
- **Тёмная адаптивная тема** — интерфейс на русском языке.

## Поддерживаемые форматы

| Формат | Расширение | Версии |
| --- | --- | --- |
| Sponge Schematic | `.schem` | v1, v2, v3 |
| Litematica | `.litematic` | все актуальные версии, включая packed blockstates |
| Structure NBT | `.nbt` | структуры Minecraft |
| Legacy Schematic | `.schematic` | старый формат MCEdit/WorldEdit |

Сжатие gzip/zlib распаковывается во встроенном `pako`, NBT разбирается собственным парсером.

## Как пользоваться

1. Откройте сайт (или запустите локально, см. ниже).
2. Перетащите схему в зону загрузки. Можно выбрать сразу несколько файлов.
3. Изучите список материалов и 3D-модель.
4. Нажмите на число в колонке «Добыто», чтобы отметить собранные блоки.
5. При желании войдите по нику — изменения будут подписаны в истории.
6. Экспортируйте проект в JSON, чтобы сделать резервную копию.

## Локальный запуск

Приложение полностью статическое. Из-за ES-модулей открывать `index.html` напрямую через
`file://` нельзя — нужен любой локальный HTTP-сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Подойдёт и `npx serve .`, и любой другой статический сервер.

## Структура проекта

```text
NexusCraft/
├── index.html          # интерфейс
├── style.css           # стили и адаптивная вёрстка
├── data.json           # демо-проект (пример списка материалов)
├── js/
│   ├── app.js          # логика приложения, хранилище, интерфейс
│   ├── schematic.js    # определение и разбор форматов схем
│   ├── nbt.js          # чтение NBT и распаковка gzip/zlib
│   ├── blocks.js       # названия, цвета и категории блоков
│   └── preview.js      # 3D-предпросмотр на Three.js
└── vendor/
    ├── pako.min.js     # gzip/zlib (pako 2.1.0)
    └── three.module.js # Three.js r160
```

## Технологии

- Чистый HTML/CSS/JavaScript (ES-модули), без сборки и бэкенда.
- [Three.js](https://threejs.org/) для 3D-предпросмотра (`InstancedMesh`).
- [pako](https://github.com/nodeca/pako) для распаковки сжатых NBT.
- GitHub Pages для хостинга.

## Ограничения

- Предпросмотр отображает до ~220 000 блоков (для очень больших схем выполняется прореживание,
  а точные количества в списке материалов всегда считаются по всей схеме).
- Для предпросмотра нужен браузер с WebGL; без него список материалов продолжает работать.
- Данные хранятся в конкретном браузере. Для переноса используйте экспорт/импорт JSON.
